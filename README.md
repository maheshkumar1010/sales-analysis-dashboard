# Sales Analysis Dashboard with Machine Learning

## Project Overview
The Sales Analysis Dashboard is an interactive web application developed using Python and Streamlit. It helps users analyze sales performance, monitor profits, understand product trends, and forecast future sales using Machine Learning.

## Technologies Used
- Python
- Pandas
- Streamlit
- Scikit-learn
- Matplotlib
- Linear Regression

## Key Features
- Calculate total sales, profit, and profit margin.
- Analyze product-wise sales and profitability.
- Interactive product and date filters.
- Visualize monthly sales performance.
- Identify top-selling and least-selling products.
- Generate business insights.
- Forecast next month's sales using Linear Regression.
- Evaluate the forecasting model using MAE and R² Score.
- Download filtered sales reports as CSV files.

## Machine Learning
Linear Regression is used to analyze historical monthly sales data and predict sales for the next month.

The model's performance is evaluated using Mean Absolute Error (MAE) and R² Score where sufficient test data is available.

## How to Run the Project

1. Install Python.
2. Install the required libraries:

   `pip install streamlit pandas scikit-learn matplotlib`

3. Open the project folder in VS Code.
4. Run the application:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Project Purpose
This project demonstrates practical skills in Python programming, data analysis, data visualization, dashboard development, and basic Machine Learning.
